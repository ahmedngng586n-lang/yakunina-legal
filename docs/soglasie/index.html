Общие условия

Разрешены только действия, необходимые для выбранной цели: сбор, запись, систематизация, хранение, уточнение, использование, предоставление доступа указанному получателю, удаление и уничтожение. Обработка смешанная. Согласие не разрешает общедоступную публикацию, передачу для рекламной рассылки и обработку для не связанных с обращением целей.

Согласие выражается активной установкой соответствующей галочки и отправкой формы или сообщения. Сайт сохраняет редакцию согласия и время принятия обращения; для повторной отправки используется тот же идентификатор. Это не подменяет электронную подпись там, где закон требует письменного согласия.

Могу отозвать согласие или запросить удаление по телефону оператора, сообщив номер обращения либо свой ранее указанный контакт. Последствия отзыва, сроки ответа и удаления определяются Федеральным законом № 152-ФЗ. Могу связаться по телефону без использования формы и чата.

Понимаю, что «сохранено» означает запись на сервере, «передано» — доставку уведомления, а конкретные время консультации, стоимость и условия услуги согласуются отдельно. Прочитал(а) политику обработки персональных данных.
