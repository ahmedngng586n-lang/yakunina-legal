# Проверка выпущенной версии 2.1

5 октября 2026 года.

- Сервер: https://yakunina.153-52-103-26.sslip.io/ — внешний HTTPS отвечает 200, версия 2.1 развёрнута в отдельном каталоге; systemd после перезапуска active.
- 24 теста прошли локально, на Ubuntu и в GitHub release workflow. JavaScript проверен перед выпуском.
- Сайт проверен браузером на ширинах 390, 768 и 1440 px: горизонтальной прокрутки нет, прайс содержит три карточки, согласие 14 px. Мобильный чат помещается в экран. Это проверка адаптивного браузера, не физического телефона.
- Из публичной формы отправлена явно помеченная тестовая заявка с вымышленным именем и адресом example.invalid. Telegram API подтвердил доставку через ChatikMoy56_bot, сервер сохранил message_id. Аналогично проверена доставка тестового сообщения из чата. Это подтверждение транспорта, не доказательство прочтения человеком.
- Публичные страницы политики и согласия, motion.js и health доступны. Запросы /server/server.py, /private/leads.sqlite3 и /config.json возвращают 404.
- Независимый агент выполнил несколько проходов; найденные ошибки срока хранения, восстановления очереди, согласия и motion исправлены. Итог в REVIEW.md.
- Figma motion-макет: https://www.figma.com/design/vufFTfJJltVSwqonwnwF1e — реальные tracks прочитаны обратно, экспорт MP4 выполнен. Реализация сайта описана в MOTION.md.
- Релиз: https://github.com/ahmedngng586n-lang/yakunina-legal/releases/tag/v2.1.0 . Архив проверен на наличие предоставленных ключей; база обращений и закрытая конфигурация исключены.

Не подтверждались: прочтение уведомления владельцем, ответ владельца через реальный Telegram, работа на физическом телефоне. AI на текущем сервере отключён; работает переписка с юристом через Telegram. Метрика без номера счётчика отключена. Фото, отзывы, адрес, часы и статус практики ожидают данных владельца; выдуманные сведения не добавлены.
