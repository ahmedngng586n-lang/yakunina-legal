# Проверка версии 3.0.0 — многостраничный сайт

6 октября 2026 года. Основной сайт: [obz-pravo.ru](https://obz-pravo.ru/).

## Структура, тексты и SEO

- Созданы 16 страниц с собственными canonical: главная, каталог услуг, шесть страниц услуг, сведения о юристе, стоимость, запись, контакты, вопросы, политика, согласие и cookie. Из них 13 предназначены для индексации; три юридические страницы имеют `noindex,follow` и не включены в sitemap.
- На каждой из шести страниц услуг размещено более 800 слов и семь вопросов FAQ. Тексты, title, description и H1 различаются по направлениям. На сайте указан статус юриста; статус адвоката, гарантии результата и неподтверждённые условия приёма не добавлены.
- Проверка `verify_site` прошла: структура, внутренние ссылки, canonical, метатеги и разметка проверены. Sitemap и robots.txt валидны.
- Все 16 опубликованных страниц на основном домене совпадают побайтно с соответствующими HTML-файлами `dist`.
- Девять старых адресов возвращают HTTP 301 с сохранением параметров запроса. Переходы с HTTP и www приводят к основному HTTPS-домену. Несуществующий адрес возвращает настоящий HTTP 404.

## Формы, доставка и адаптивность

- 28 серверных тестов прошли локально и при развёртывании.
- Сайт проверен в браузере на ширинах 320, 390, 768 и 1280 px: горизонтального переполнения не обнаружено. Это адаптивная браузерная проверка; работа на физическом телефоне отдельно не подтверждалась.
- Проверены ошибки неполного/неверного номера телефона и отправки без согласия. Поля формы и сообщение об ошибке помогают исправить ввод до отправки.
- Из публичной версии отправлена помеченная тестовая заявка. Сервер принял обращение `7465011e5074`; Telegram API вернул успешную отправку (`sent: true`), `message_id: 2755`. Это подтверждает передачу уведомления API Telegram, но не прочтение или получение ответа человеком.
- Автоматический ИИ-помощник выключен. Работает переписка с юристом через Telegram.

## Поисковые кабинеты, аналитика и скорость

- В Google Search Console подтверждена повторная отправка sitemap. На момент проверки кабинет показывал прежние семь обнаруженных URL; новый sitemap содержит 13 URL. Их новый обход и индексация ещё ожидаются.
- Повторная отправка sitemap в Яндекс Вебмастер не подтверждена: соединение сбрасывалось (`connection reset`). Успешный результат в этом кабинете не заявляется.
- Счётчик Яндекс Метрики № 113437050 сохранён. Реализованы шесть событий: `phone_click`, `max_click`, `email_click`, `chat_open`, `message_sent`, `lead_created`. Аналитика загружается после отдельного разрешения посетителя. Измерение всех целей в кабинете в этот день не подтверждалось.
- PageSpeed Insights API вернул HTTP 429. Поэтому актуальные оценки PageSpeed и фактический LCP для версии 3.0.0 не получены; утверждение о достижении LCP менее 2,5 секунды не делается.

Это адаптивная проверка браузера, не физического телефона.

24 серверных теста прошли при развёртывании. SEO, внутренние ссылки и синтаксис нового JavaScript проверены. Сервер active, Telegram и переписка доступны по health. В этом обновлении новые тестовые обращения не отправлялись; доставка проверялась в предыдущем релизе.
