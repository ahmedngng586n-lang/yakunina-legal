# Проверка и запуск версии 3 — 06.10.2026

Это контрольный список владельца и разработчика. Отметка «сделано» ставится только после фактической проверки. Документ сам по себе не подтверждает индексацию, наличие карточки или работу сервиса.

## Техническая проверка перед переключением

- [ ] Проверить 16 маршрутов из `semantic-plan-v3.md`: HTTP 200, русский текст, уникальные title/description, один H1, canonical на соответствующий новый URL.
- [ ] Проверить старые `.html`-адреса: 301/308 на правильные новые маршруты, без цепочек. HTTP и www приводят на HTTPS/apex, путь и рекламные параметры сохраняются.
- [ ] Проверить неизвестный адрес: настоящий HTTP 404 и страница с полезными ссылками; исключить выдачу главной с 200 вместо ошибки.
- [ ] Проверить ссылки, меню, хлебные крошки, цены и запись. Юридическая услуга ведёт на нужную страницу, а не обратно к общему чату.
- [ ] Проверить JSON-LD: LegalService/Person/Service/BreadcrumbList; FAQPage соответствует видимым ответам. Нет выдуманных рейтингов, координат, часов и адвокатских данных.
- [ ] Проверить sitemap.xml: новые canonical, корректный XML и MIME, только доступные страницы. Проверить robots.txt: обход нужных разделов разрешён, API исключён; robots не используется для защиты заявок.
- [ ] Проверить favicon, OG-изображение, alt, width/height и lazy-loading вторичных иллюстраций. Главный портрет не подменяется изображением другого человека.
- [ ] Проверить 320, 390, 768 и 1280 px: нет горизонтальной прокрутки, меню/аккордеоны/согласия доступны с клавиатуры и сенсора, нижняя панель не закрывает отправку формы. Проверить реальный телефон отдельно.
- [ ] Проверить контраст и фокус; основной текст новых внутренних страниц — от 16 px. Анимации учитывают reduced motion, не задерживают чтение и взаимодействия.
- [ ] Проверить скорость на опубликованном домене в PageSpeed Insights и DevTools. Цель LCP < 2,5 с — целевой показатель; записать фактическое измерение, устройство и сеть. Проверить CLS и INP. Лабораторный результат не выдавать за полевые данные.
- [ ] Отправить контрольную заявку с ясной пометкой «ТЕСТ», убедиться в получении Telegram и ответа формы. При ошибке сети форма не сообщает об успехе. Проверить телефон/MAX с реального телефона.
- [ ] Проверить валидацию контакта, обязательное отдельное согласие, honeypot, ограничения частоты и сохранение текста при исправлении ошибки. Не публиковать API-ключи, Telegram-токен, конфигурацию и пользовательские данные.

Готовые страницы политики/согласия/cookie и работающий чекбокс — только элементы интерфейса. Они не доказывают законность фактического сбора, хранения и передачи данных.

- [ ] Владелец подтверждает оператора, контакт для запросов субъектов, состав данных, цели, основания, сроки хранения, порядок удаления и получателей.
- [ ] Проверить реальную схему хостинг → сервер/БД → Telegram, доступы к боту, резервные копии и журналы. Не заявлять «всё хранится только в РФ» без подтверждённых мест хранения и договоров.
- [ ] Проверить применимость уведомления РКН и требований к трансграничной передаче/локализации по реальной схеме; оформление уведомлений не выполнено в рамках разработки. [Портал Роскомнадзора](https://pd.rkn.gov.ru/). Прямые страницы портала во время точечной проверки не загрузились; подачу и статус нужно проверить владельцу.
- [ ] Не просить в публичной форме паспорта, полные документы, сведения о здоровье/третьих лицах. Сначала короткое описание, для документов согласуется подходящий способ передачи.
- [ ] Если подключается ИИ-сервис, отдельно проверить передачу данных и информирование посетителя. Для текущего сайта автоматическая юридическая консультация не обещается.

2. **[ЗАПОЛНИТЬ]** Точные дни и часы приёма; кабинет/этаж, вход и ориентир; требуется ли предварительная запись. Сейчас подтверждён только адрес Бузулук, ул. 1 Мая, 37а.

4. **[ЗАПОЛНИТЬ]** Продолжительность консультации, способы оплаты, срок ответа; готовность к бесплатному вводному звонку. До подтверждения эти обещания не добавлять.
