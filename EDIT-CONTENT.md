# Как добавить свои данные позже

Откройте `dist/assets/site-config.js`. Это публичные настройки, поэтому здесь нельзя хранить ключи, токен бота или заявки клиентов. Пустые поля не отображаются на сайте.

- `maxProfileUrl` — настоящая HTTPS-ссылка на профиль из MAX. Номер телефона не заменяет ссылку на профиль.
- `telegramProfileUrl` — ссылка `https://t.me/...` именно на профиль Светланы.
- `metrikaId` — числовой номер вашего счётчика; ноль оставляет Метрику выключенной.
- `photo` — путь к реальному фото, например `assets/svetlana.jpg`; сам файл положите в `dist/assets`.
- `address`, `hours`, `consultationDuration`, `paymentMethods`, `practiceStatus`, `courtScope` — подтверждённые условия работы.
- `callbackPromise` — подтверждённый срок звонка, например «Перезвоню в течение двух часов в рабочее время». Пока поле пустое, срок не обещается.
- `yandexBusinessUrl`, `twoGisUrl` — ссылки на существующие карточки.

Отзывы и примеры работ должны быть настоящими. Фото в исходном резюме отсутствует; вымышленные отзывы, достижения и портрет не добавлялись. Создание карточек Яндекс Бизнеса/2ГИС, домена и хостинга требует данных владельца и доступа к соответствующим сервисам.

На GitHub Pages форма обратного звонка не отправляет заявки: там показано честное сообщение о недоступности и прямое действие через SMS. На серверной версии есть форма «имя + телефон» с `/api/lead`. Само наличие формы и сохранение записи не означают, что уведомление доставлено в Telegram. Для полного запуска нужны сервер, HTTPS, секреты бота и ID получателя, затем проверка фактического получения тестовой заявки.

Для Метрики подготовлены цели `phone_click`, `lead_submit`, `callback_submit`, `callback_open`, `messenger_click`, `telegram_click`, `sms_click`. До рекламы задайте номер счётчика и проверьте получение целей в своём кабинете.
