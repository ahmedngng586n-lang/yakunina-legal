# Публичные данные сайта

Изменяйте `dist/assets/site-config.js`; после изменения обновляйте копию в `docs`. Секреты бота и данные клиентов в этот файл не помещаются.

- `apiBaseUrl` — HTTPS-адрес серверной части для Pages. На самом сервере и при локальном запуске используется тот же origin.
- `metrikaId` — номер счётчика; `0` отключает Метрику.
- `telegramProfileUrl`, `maxProfileUrl` — подтверждённые ссылки для прямого общения с юристом.
- `photo` — реальная фотография юриста. Изображение папки документов не является портретом.
- `address`, `hours`, `consultationDuration`, `callbackPromise`, `paymentMethods`, `practiceStatus`, `courtScope` — подтверждённые условия; пустые значения не создают обещаний.
- `yandexBusinessUrl`, `twoGisUrl`, `reviews`, `cases` — реальные карточки и подтверждённые материалы.

Факты опыта и образования сохранены из исходного сайта. Адрес, часы, срок ответа, отзывы и результаты дел не выдуманы. Начальные цены — из исходного прайса; окончательная стоимость согласуется после уточнения задачи. Сервер проверяет цену по выбранному формату, а не доверяет значению из браузера.

Для Telegram используйте закрытую серверную конфигурацию и персональную привязку владельца. После подключения проверьте реальную доставку помеченной заявки, работу кнопок этапов и ответа в чат сайта.
