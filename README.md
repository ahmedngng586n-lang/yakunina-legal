# Лендинг Светланы Якуниной · версия 8, заявки в Telegram и подготовка к Директу

## Что работает

Сайт: http://127.0.0.1:9137/ при работающем сервере.

- Основной виджет — светлый блок «Выберите вашу ситуацию» справа на первом экране. Он меняет содержимое на месте: тема → формат помощи → описание → сводка, начальная цена и «Записаться». Запись раскрывает контакты в этом же блоке. Виджет не открывает чат, модальное окно или другую страницу.
- Кнопка «Задать вопрос» слева и плавающая кнопка справа снизу открывают один общий отдельный чат через AI STAR. Ответы не более 100 слов; после третьего успешного ответа — сводка, начальная цена и запись внутри чата. Чат обозначен как автоматический помощник. Ключ хранится вне сайта, история не сохраняется после перезагрузки.

Помощник настроен системными инструкциями и подтверждёнными данными практики. Это настройка поведения, а не дообучение весов. Он даёт предварительное объяснение, уточняет обстоятельства и предлагает индивидуальную работу со Светланой. Инструкции ограничивают тематику правом, запрещают вымышленные достижения, гарантии исхода, выдачу себя за человека и уход в посторонние задачи. Эти инструкции не являются математической гарантией поведения языковой модели. У модели нет поиска по актуальным нормативным базам: точные нормы и сроки должны проверяться юристом.

Инструкции можно редактировать в `server/assistant-instructions.md`; затем перезапустить сервер. Имя, город, телефон, образование и профессиональный опыт взяты из резюме. Предложенный прайс и исследование — `market-prices.md`. Папка и ручка на фото — предметная композиция ImageGen.

## Запуск

Python установлен на этом компьютере, дополнительных пакетов нет. Выполните `start-local.ps1` из PowerShell. Скрипт использует локальную конфигурацию в папке `work` этого проекта. Ключ не находится в папке сайта, архиве или JavaScript. Конфигурацию не публиковать.

Для другого компьютера / хостинга задайте переменные окружения `LEGAL_AI_API_KEY`, `LEGAL_AI_BASE_URL` (https://ai.starimg.ru/v1), `LEGAL_AI_MODEL` (deepseek-v4.1-flash), затем запустите `python server/server.py`. Порт по умолчанию 9137, адрес 127.0.0.1. Параметры `--port` и `--host` позволяют изменить прослушивание; публичный доступ должен идти через сервер с HTTPS.

Открытие `dist/index.html` напрямую сохраняет форму и контакты, но ИИ требует сервер. Статический хостинг сам по себе не запускает ИИ-чат. Сайт сейчас работает локально; публикации в интернете нет, Sites недоступен в рабочем пространстве.

## Проверка и ограничения

Проверены: ответ настоящей модели, отказ от просьбы написать игру и сменить роль, правильные контакты и цена консультации, форма обращения, мобильная ширина 390 px. Защита API отклоняет системные сообщения от клиента, запросы с чужого origin и запросы без специального заголовка; ограничения — 12 запросов в минуту на IP, три параллельных генерации, ограниченная длина входа и ответа. Для публичного большого трафика нужны постоянные лимиты на уровне хостинга; текущие сбрасываются при перезапуске сервера.

Один замер запроса о проверке договора аренды: первый текст 1,64 с, весь ответ 3,15 с. Это не гарантия скорости. Тестовые обращения расходуют токены предоставленного ключа, как и будущие ответы посетителям.

GSAP/ScrollTrigger 3.15.0 и Lenis 1.3.26 остаются локальными; reduced motion отключает анимацию. Сервер выдаёт только папку `dist`; ключ и инструкции не доступны как файлы сайта.


## Заявки и Telegram

Кнопка «Записаться» раскрывает форму в основном виджете или внутри чата. При сообщении с просьбой о консультации чат также предлагает контактную форму. После заполнения имени, контакта и согласия `/api/lead` сохраняет заявку в SQLite и отправляет её юристу: кто, контакт, тема, услуга, начальная цена, текст запроса, рекламные метки. Само анонимное сообщение в чате не создаёт заявку.

Для хостинга задайте `LEGAL_TELEGRAM_TOKEN` и `LEGAL_TELEGRAM_CHAT_ID`. ID личного чата получают после того, как получатель начал переписку с ботом. Локальная конфигурация дополнительно позволяет привязать владельца по username и точному сообщению «Подключить сайт 9137». Username сам по себе не является chat_id для отправки личного сообщения.

Если Telegram недоступен, заявка сохраняется и повторяется каждые 30 секунд с увеличением задержки до 10 минут. Посетитель видит реальное состояние: сохранена с задержкой либо передана. Повторная отправка одной формы не создаёт дубликат. Доставленные записи удаляются с сервера через 30 дней; недоставленные остаются до успешной передачи. Telegram может сохранить свою копию сообщения.

На 04.10.2026 Telegram API недоступен с этого компьютера по TCP 443. Реальная доставка не подтверждена, ID владельца ещё не получен. Unit-тесты проверяют очередь, повторную отправку, согласие, цену и привязку владельца с имитацией Telegram; это не реальная отправка.

## Директ и публичный сервер

См. `direct-setup.md`. UTM и yclid включаются в заявку; цели подготовлены, но счётчик выключен до получения номера Метрики. Никаких контактов и текста обращения в цели не передаётся.

Docker: `docker build -t legal-site .`, затем `docker run --env-file /secure/legal.env -p 9137:9137 -v legal-data:/app/private legal-site`. Файл окружения содержит четыре основных секрета/настройки: `LEGAL_AI_API_KEY`, `LEGAL_TELEGRAM_TOKEN`, `LEGAL_TELEGRAM_CHAT_ID`, а также при необходимости `LEGAL_AI_BASE_URL` и `LEGAL_AI_MODEL`. Нужен HTTPS-прокси перед сервером. Не храните секреты в GitHub. GitHub Pages не выполняет Python и не обеспечивает чат или передачу заявки.

Проверка бэкенда: `python -m unittest discover -s server -p test_leads.py -v`.
