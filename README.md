# Светлана Якунина — юридические консультации в Бузулуке

Публичный сайт: https://ahmedngng586n-lang.github.io/yakunina-legal/

## Версия 1.1: простой путь к звонку

Первый экран: конкретный заголовок, консультация от 1 500 ₽, одно основное действие «Позвонить». Пошаговый виджет перенесён ниже и раскрывается по желанию. Плавающая кнопка чата и форма копирования обращения удалены. Прайс состоит из трёх строк. На мобильном экране закреплена панель «Позвонить / Написать / Заказать звонок».

Без подтверждённой ссылки на профиль «Написать» открывает SMS на известный номер. После добавления ссылки в `dist/assets/site-config.js` кнопка ведёт в MAX или Telegram. Фото, отзывы, адрес, часы, статус практики и срок ответа не выдуманы: их можно заполнить позже. Инструкция — `EDIT-CONTENT.md`.

## Заявки и чат

На Python-сервере форма обратного звонка отправляет имя и телефон в `/api/lead`. Сервер проверяет согласие и номер, сохраняет заявку в SQLite, предотвращает дубликаты и повторяет доставку в Telegram. Уведомление содержит имя, контакт, запрос, канал и рекламные метки. Сервер определяет цену сам.

GitHub Pages обслуживает статические файлы. На публичной версии форма обратного звонка и AI-чат выключены; посетителю доступны звонок и SMS без копирования текста. Никакая заявка не считается доставленной только потому, что она сохранена. На 04.10.2026 соединение с Telegram API на этом компьютере не установлено, реальная доставка боту не подтверждена. Получатель бота требует chat_id после начала переписки; одного username недостаточно.

В локальной серверной версии чат вторичен и находится в контактах. Ответы ограничены 100 словами; после трёх ответов интерфейс предлагает сводку и запись. История не сохраняется при перезагрузке. Это настройка системными инструкциями, не обучение весов модели.

## Запуск и хостинг

Запуск на этом компьютере: `start-local.ps1`, затем http://127.0.0.1:9137/.

На другом сервере задайте переменные окружения `LEGAL_AI_API_KEY`, `LEGAL_TELEGRAM_TOKEN`, `LEGAL_TELEGRAM_CHAT_ID`. Дополнительно можно задать `LEGAL_AI_BASE_URL` (по умолчанию https://ai.starimg.ru/v1) и `LEGAL_AI_MODEL` (deepseek-v4.1-flash). Запуск: `python server/server.py --host 0.0.0.0 --port 9137`. Нужен HTTPS-прокси и постоянный закрытый каталог для SQLite.

Docker: `docker build -t legal-site .`, затем `docker run --env-file /secure/legal.env -p 9137:9137 -v legal-data:/app/private legal-site`. Секреты, SQLite и персональные обращения не должны попадать в GitHub. Сервер выдаёт только `dist`.

## Проверка

`python -m unittest discover -s server -p test_leads.py -v`: пять тестов согласия, цены, дублей, повтора доставки, привязки получателя и проверки телефона. Telegram в тестах имитируется; эти тесты не доказывают реальное получение уведомления. Форма проверена через локальный сервер, мобильная вёрстка — в браузере на ширине 390 px. Проверки на физическом телефоне не было.

## Реклама

Метки UTM и yclid сохраняются в пределах вкладки и включаются в заявку. Реальная Метрика выключена до заполнения `metrikaId` в `site-config.js`. Цели перечислены в `EDIT-CONTENT.md` и `direct-setup.md`. Личные данные и текст обращений не передаются в цели, Вебвизор выключен. Кампании в Директе, карточки Яндекс Бизнеса и 2ГИС не созданы. Перед запуском рекламы нужны подтверждённые условия работы, реквизиты, Метрика и реальная проверка доставки.
